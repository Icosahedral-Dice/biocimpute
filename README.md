# biocimpute

A Python port of the Bioconductor package
[impute](https://bioconductor.org/packages/release/bioc/html/impute.html)
(version 1.86.0): k-nearest-neighbor imputation of missing values in gene
expression matrices, with recursive two-means clustering for large matrices.

Results match R's `impute.knn` exactly, including the random two-means split
(R's Mersenne-Twister `set.seed()`/`sample()` are reimplemented). The test
suite checks every imputed value against fixtures generated by the R package.

## Installation

```sh
uv add biocimpute            # or: pip install biocimpute
uv add "biocimpute[pandas]"  # DataFrame support and the khanmiss dataset
```

## Usage

```python
import numpy as np
from biocimpute import impute_knn, load_khanmiss

# Same as R: khan.expr <- khanmiss[-1, -(1:2)]; impute.knn(as.matrix(khan.expr))
khan_expr = load_khanmiss().iloc[1:, 2:].to_numpy(dtype=float)
result = impute_knn(khan_expr)
result.data      # imputed matrix
result.rng_seed  # 362436069
```

`impute_knn(data, k=10, rowmax=0.5, colmax=0.8, maxp=1500, rng_seed=362436069)`
takes the same arguments as `impute.knn` (genes in rows, samples in columns,
missing values as NaN). A pandas DataFrame input gives a DataFrame output
with the same index and columns, as R keeps dimnames.

| R | biocimpute |
|---|---|
| `impute.knn(...)` | `impute_knn(...)` |
| `rng.seed` | `rng_seed` |
| `$data`, `$rng.seed` | `.data`, `.rng_seed` |
| `$rng.state` | not returned: biocimpute never touches a global RNG |
| `stop(...)` on `colmax` | `ValueError` |
| `warning(...)` on `rowmax` | `UserWarning` |
| `cat("Cluster size ...")` | `logging.getLogger("biocimpute").info(...)` |
| `data(khanmiss)` | `load_khanmiss()` |

## Behavior inherited from R

For parity, these behaviors of `impute.knn` are kept:

- Two-means clustering (when there are more than `maxp` rows) runs on the
  matrix with missing values replaced by 0.
- In a cluster with at most `k` rows, missing values are left as 0.
- If exactly one row has more than `rowmax` missing, its missing values are
  left as 0. With two or more such rows, column means are used.
- A column with no observed values among the rows used for KNN stays NaN.

The one deliberate difference: when a block has `k` or fewer rows, R's
Fortran reads past the end of its neighbor array (undefined behavior).
biocimpute uses all other rows of the block as neighbors.

## Layout

The code follows the R package's structure:

- `src/biocimpute/_impute.py`: `R/allknnimp.R`, one function per R function
- `src/biocimpute/_kernels/`: `src/knnimpute.f`, ported to Numba. The
  `_kernels` package is the only place a backend is imported, so another
  backend (e.g. Rust) can be swapped in there.
- `src/biocimpute/_rng.py`: R's default RNG and `sample()`
- `reference/`: the original R and Fortran sources

## Development

```sh
uv sync
uv run pytest
```

To regenerate the R fixtures in `tests/fixtures` (needs R and gfortran):

```sh
tests/r/install_impute.sh          # installs impute into tests/r/lib
Rscript tests/r/generate_fixtures.R
```
